# KJC Pro Student Portal
Python + Flask + MySQL + HTML5 + CSS3 + JavaScript.

Windows:
1. Install Python 3.11+ and MySQL 8+.
2. Execute schema.sql in MySQL Workbench.
3. Copy .env.example to .env and set DB_PASSWORD.
4. PowerShell in this folder:
   python -m pip install -r requirements.txt
   python seed.py
   python app.py
5. Open http://127.0.0.1:5000

Student: student@kjc.edu.in / student123
Admin: admin@kjc.edu.in / admin123

No XAMPP required.
Replace static/media/campus_bg.mp4 with authorized KJC footage if desired.
